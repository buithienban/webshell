### LƯU Ý QUAN TRỌNG

Mã nguồn này được chia sẻ hoàn toàn nhằm mục đích **nghiên cứu, phân tích và phòng chống mã độc**. Tài liệu giúp người đọc nhận diện cơ chế hoạt động của các script nguy hiểm chuyên khai thác lỗ hổng hệ thống để tải lên tệp PHP trái phép (Web Shell), hoặc chèn ngầm mã độc (Backdoor) vào các bộ mã nguồn mở trước khi phát tán đến người dùng.

Thông qua việc nắm rõ cấu trúc và phương thức vận hành của chúng, các lập trình viên cùng quản trị viên hệ thống có thể chủ động rà soát, phát hiện sớm và triển khai các biện pháp bảo mật, vá lỗ hổng kịp thời. *Nghiêm cấm sử dụng mã nguồn này vào các mục đích phá hoại hoặc vi phạm pháp luật dưới mọi hình thức.*
### IMPORTANT NOTICE

This source code is shared strictly for the purposes of **research, analysis, and malware prevention**. It is intended to help readers understand the operational mechanisms of malicious scripts—specifically those that exploit system vulnerabilities to upload unauthorized PHP files ("Web Shells") or inject "backdoors" into open-source software before it is distributed to users.

By gaining insight into the structure and operational methods of such scripts, developers and system administrators can proactively audit their environments, detect threats early, and implement security measures or patches in a timely manner. *The use of this source code for destructive purposes or any form of illegal activity is strictly prohibited.*
